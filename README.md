# Implementación de Filtros Digitales

## Descripción

Proyecto realizado para la implementación y evaluación de filtros digitales utilizando Python.

Se diseñaron filtros pasa bajos, pasa altos y pasa bandas mediante filtros Butterworth para analizar señales con ruido.

## Herramientas utilizadas

- Python
- NumPy
- SciPy
- Matplotlib
- Visual Studio Code

## Filtros implementados

### Filtro pasa bajos
Permite el paso de frecuencias bajas y reduce frecuencias superiores.

### Filtro pasa altos
Permite el paso de frecuencias altas eliminando componentes bajas.

### Filtro pasa bandas
Permite seleccionar un rango específico de frecuencias.
